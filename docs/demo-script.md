# Demo script

## Success path

1. Create a Notion bug and show it in Tasks.
2. Manually create its GitHub issue.
3. Prepare a patch and inspect baseline steps, analysis, diff, and tests.
4. Approve and show the `agent/*` branch.
5. Open and merge the PR manually; show the task becoming Done.

## Safety path

1. Open an external GitHub issue that asks for a migration or credential access.
2. Accept or link it after Inbox review.
3. Prepare a patch and show policy refusal with no branch pushed.
